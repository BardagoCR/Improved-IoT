Activity 6 — Create IoT Data Models
Objective
Create TypeScript models that describe the application's IoT data.
Create:
src/
└── models/
    └── IoTModels.ts
Create Device
type Device = {
    id: number;
    name: string;
    type: string;
    icon: keyof typeof Ionicons.glyphMap;
    status: boolean;
};
Create SensorData
type SensorData = {
    temperature: number;
    humidity: number;
    lightLevel: number;
};
You should also create sample devices.
Example:
Living Room Light
Bedroom Fan
Front Door Lock

Each device has an icon.
Each device has a status.
status is a Boolean.

Sensor data contains humidity.
Sensor data contains light level.
created sample IoT devices.

Activity 10 — Create the IoT Service
Objective
Simulate communication with an IoT API.
Create:
src/
└── services/
    └── IoTService.ts
Students must implement:
getSensorData()
getDevices()
updateDeviceStatus()
Requirements
The service should:
Use async/await.
Simulate network delays.
Return sensor data.
Return devices.
Update device status.
Simulate possible failures.
Example:
await delay(1500);
Students should understand that the service represents communication with an actual IoT backend.
Mobile App
    │
    ▼
IoTService
    │
    ▼
Simulated IoT API


Checkpoints:
IoTService.ts exists.
getSensorData() works.
getDevices() works.
updateDeviceStatus() works.
The functions use asynchronous operations.
A simulated delay is present.
The screens do not directly generate the IoT data.
The Context communicates with the service.
